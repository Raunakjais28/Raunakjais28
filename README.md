### 🚀 Featured Projects

#### 🚁 Guardian Hawk: Multi-Rotor Autonomous UAV System &nbsp;`In progress`
AI-powered disaster-response and decision-support drone that detects survivors from the air and helps prioritize rescue.

- **Airframe:** F450 quadcopter, Pixhawk 2.4.8 (ArduPilot), 1400KV BLDC motors, 30A ESCs, LiPo power
- **Sensing:** TF-Luna LiDAR over UART for proximity sensing and obstacle avoidance; 2-axis pan-tilt gimbal via PWM pass-through
- **AI onboard:** Raspberry Pi 4 talking to the flight controller over MAVLink, running YOLO object detection and streaming telemetry
- **Flight tuning:** IMU, compass and ESC calibration, PID loop tuning for stable low-vibration flight

`ArduPilot` `Pixhawk` `MAVLink` `YOLO` `Raspberry Pi` `Python`

#### 🎬 [Netflix UI Clone](https://netflix-clone-raunak28.vercel.app/)
Responsive landing page built with semantic HTML5 and CSS3 (Grid/Flexbox), cross-browser tested, deployed on Vercel through a Git workflow.

`HTML5` `CSS3` `Git` `Vercel`

#### 🤖 Dual-Mode Hybrid RF & Autonomous Robot
Vehicle that hot-swaps between manual control from a FlySky i6 transmitter and autonomous navigation. Decodes multi-channel PWM on Arduino, scans 180° with HC-SR04 + servo, and drives high-torque motors through a BTS7960 driver.

`Arduino` `C` `PWM` `Sensors`
